# AI Contact Centre PoC

An AI-powered contact centre proof of concept built using Amazon Connect, Amazon Lex V2, AWS Lambda, Amazon Bedrock and DynamoDB.

## Current Features

- Voice self-service
- Web chat
- Case status lookup
- Document request
- Transfer to adviser
- Bedrock AI responses
- DynamoDB customer records

## Technology Stack

- Amazon Connect
- Amazon Lex V2
- AWS Lambda (Python)
- Amazon Bedrock (Nova Lite)
- Amazon DynamoDB
- CloudWatch
